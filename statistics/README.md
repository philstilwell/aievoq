# Permanent statistical census

Five recurring departments: business adoption, employment pressure, capability on a specified mathematics test, standard operating prices, and data-centre electricity. The first release is reviewed through **2026-10-28**, during an incomplete Q4.

`index.html` contains readable static data tables, definitions, sources and download links. `statistics.js` progressively adds five SVG charts from `data/snapshot-2026-10-28.json` and two chart controls. If JavaScript or the data fetch fails, the evidence remains readable. `statistics.css` extends the existing site's ivory, charcoal, copper and cobalt design. No dependencies, trackers, external fonts or paid model calls.

## Update contract

- Archive each new reviewed release under a fresh date/version. Preserve dated files already published. Corrections receive a new version and a public explanation.
- Separate observation, publication and retrieval dates. Keep historical estimates, expected use and forecasts visibly distinct.
- Adoption: final reference window wholly inside a quarter; last cross-quarter window separate. Historical snapshots use the October source vintage, not an as-known-at-quarter-end archive. Earlier narrower questions belong to another series.
- Employment: compare quarter-end months when published. These are annual growth rates from an ADP payroll sample, not counts of AI-caused losses. Preserve the age and exposure groups and source-vintage status.
- Capability: match conjectures, tools, budget and scoring. Start a new series if comparison rules change. Initial baseline only; do not reconstruct old leaderboards from model release dates.
- Prices: track the exact same models and tiers. New entrants separate, retirements unavailable. Fixed billed text volume is not equal quality, equal tokenization or a market price index.
- Energy: annual estimates; forecast revisions tracked by source edition. Never interpolate quarterly usage or treat the 2030 projection as historical consumption.
- Update the JSON pointer, static tables, headline numbers, captions, review dates and archive together. Check calculations and dates against preserved primary evidence, then verify charts, downloads, narrow screens and no-JavaScript table availability.

The magazine's local production folder contains the source-extraction script and detailed research notes. The public release contains the derived data and source links, not the working PDF. Updates are reviewed before publication; the three-day research watch does not automatically publish.
